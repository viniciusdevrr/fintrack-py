# FinTrack — App de Finanças Pessoais (Web + Mobile)

Aplicativo completo de controle financeiro, acessível pelo navegador e instalável
como app no celular (PWA). Desenvolvido em Python (FastAPI) com banco de dados,
autenticação, análise de dados e machine learning.

## Funcionalidades
- Dashboard com saldo, receitas e despesas do mês
- Categorias personalizadas
- Cartões de crédito com fatura e parcelamento
- Metas financeiras
- Calendário de vencimentos
- Relatórios e gráficos comparativos
- Alertas de limite e vencimento
- Assistente de perguntas sobre os próprios gastos
- Detecção de despesas recorrentes
- Simulador de orçamento
- Autenticação segura (JWT)

## Tecnologias
Python, FastAPI, SQLAlchemy, PostgreSQL/SQLite, JWT, Pandas, Matplotlib,
HTML/CSS/JS, PWA
